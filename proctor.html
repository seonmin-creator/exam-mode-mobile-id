카메라 권한 허용하는 방법

안드로이드 크롬 주소창 왼쪽 아이콘(⚙ 또는 ⓘ) → 권한 → 카메라 → 허용
안 보이면: 크롬 ⋮ → 설정 → 사이트 설정 → 카메라 → exam.3smk.uk → 허용

삼성 인터넷 주소창 자물쇠 아이콘 → 권한 → 카메라 → 허용

아이폰 사파리 주소창 왼쪽 가가 아이콘 → 웹 사이트 설정 → 카메라 → 허용
또는 설정 앱 → 앱 → Safari → 카메라 → 허용

그래도 안 되면 폰 설정 → 애플리케이션 → Chrome(또는 사용 중인 브라우저) → 권한 → 카메라 허용

허용하고 이 화면으로 돌아오면 카메라가 자동으로 켜집니다. 안 켜지면 [카메라 켜기]를 눌러 주세요.
